## Recognition composition

One `ciborium::Value` tree crosses the trust boundary. The recogniser checks
complete consumption, recursively detects duplicate canonical keys,
re-encodes with RFC 8949 deterministic ordering, validates the same tree with
the checked-in CDDL, and only then extracts the public typed value.

The application identifier uses an exact safe scanner for the checked-in ABNF.
The relay origin first passes the URL parser and then must equal its canonical
HTTPS or WSS origin serialization. The crate continues to forbid unsafe code.
