## Requirement attribution

The failures attribute only to
`SPEC-072-unified-pairing-mailbox#TEST-005`. The repair scope is `src/wire.rs`
and its declared grammar dependencies.

The chosen composition uses one ciborium decode tree. cddl-cat validates that
tree against `schemas/pairing-v1.cddl`. cbor2 deterministically re-encodes the
same tree for byte comparison.

The Red Gate initially selected static-regular-grammar for the application-id
ABNF. Implementation review rejected that choice because its derive expands
local unsafe code under this crate's `forbid(unsafe_code)` boundary. The green
implementation instead uses an exact safe scanner for this small regular
grammar. The `url` crate supplies RFC URL recognition before the protocol
checks canonical origin constraints.
